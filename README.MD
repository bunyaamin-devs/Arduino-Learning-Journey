# Arduino-Learning

A collection of Arduino projects, experiments, and learning exercises from my journey into embedded systems, robotics engineering, and hardware programming.

This repository documents my hands-on practice with Arduino, electronics, LEDs, timing logic, binary representation, and embedded programming concepts as I continue building a strong foundation in mechatronics, robotics, and real-world hardware + software development.

## 📚 Projects Included SO FAR
- LED Blink
- Three LED Blink
- Traffic Light System
- LED Binary Counter (1 - 31)
- Voltage Monitor


## 🎯 Goals
- Strengthen my understanding of embedded systems
- Learn practical electronics and microcontroller programming
- Build real-world hardware + software projects
- Prepare for robotics and IoT development
