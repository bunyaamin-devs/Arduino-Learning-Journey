# LED Blink

A beginner Arduino project that allows input of the number of blinks one wants in the LED. For loop is used to collect the number from the Serial Monitor and executes the number of blinks in the LED.

## Concepts Learned
- `print.available()`
- `print.ParseInt`  

## 📚 Concepts Used
- Arduino structure (`setup()` and `loop()`)
- Digital output
- `pinMode()`
- `digitalWrite()`
- `delay()`

## 🛠️ Components Used
- Arduino board
- LED
- Resistor
- Breadboard
- Jumper wires
