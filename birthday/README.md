# BIRTHDAY SONG

This project uses an Arduino and a passive buzzer to play the "Happy Birthday" melody. The goal of the project was to learn how sound can be generated using a microcontroller by controlling the frequency and duration of notes through programming.

## 📚 Concepts Used
- Arduino structure (`setup()` and `loop()`)
- Analog Input
- `pinMode()`
- `delay()`
- `tone(frequency, delay)`
- `digitalRead()`

## 🛠️ Components U`sed
- Arduino board
- Passive buzzers
- Resistors
- Breadboard
- Jumper wires
- Photoresistor
