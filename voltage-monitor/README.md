# VOLTAGE MONITOR

A beginner Arduino project that monitors and responds to changes in circuit voltage using a potentiometer. As the resistance of the potentiometer is adjusted, the Arduino reads the changing voltage level and controls three LEDs to indicate the current voltage range of the circuit.

- Green LED → 2V – 3V  
- Yellow LED → 3V – 4V  
- Red LED → 4V – 5V  

This project demonstrates analog input reading, voltage monitoring, and real-time response using Arduino and basic electronic components.

- `pinMode()`
- `delay()`
