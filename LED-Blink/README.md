# LED Blink

A beginner Arduino project that blinks a single LED repeatedly using digital output and timing functions.

## 📚 Concepts Learned
- Arduino structure (`setup()` and `loop()`)
- Digital output
- `pinMode()`
- `digitalWrite()`
- `delay()`

## 🛠️ Components Used
- Arduino board
- LED
- Resistor
- Breadboard
- Jumper wires
