# Voltage Read

A beginner Arduino project that checks the voltage passing through a resistor, making use of the analog plug in. The project is made possible using analog reading and timing functions.

## 📚 Concepts Used
- Arduino structure (`setup()` and `loop()`)
- Analog Output
- `pinMode()`
- `analogRead()`
- `delay()`

## 📚 Concepts Used
- `analogRead()`
- `analogRead()`
- `Serial.begin()`
- `Serial.println()`

## 🛠️ Components Used
- Arduino board
- LED
- Resistors
- Breadboard
- Jumper wires
