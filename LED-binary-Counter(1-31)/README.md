# LED Binary Counter (1–31)

An Arduino project that uses LEDs to represent binary numbers from 1 to 31 using a multi-LED system.

This project extends the basic binary counter concept by increasing the range from 1–15 to 1–31, improving understanding of binary representation and digital output control.

## 📚 Concepts Learned
- Binary number system (extended range)
- Bit patterns using LEDs
- Digital output control with Arduino
- Scaling logic from 4-bit to higher bit representation
- Timing and sequential counting

## 🛠️ Components Used
- Arduino board
- LEDs (5 or more depending on implementation)
- Resistors
- Breadboard
- Jumper wires

## ⚙️ How It Works
Each LED represents a binary bit:
- LED OFF = 0
- LED ON = 1

The Arduino cycles through numbers 1 to 31, converting each number into its binary form and displaying it using LEDs.

## 🚀 Outcome
This project demonstrates how digital systems represent and process numbers using binary logic, forming a foundation for microcontrollers and computer systems.
