# Three LED Blink

An Arduino project that controls and blinks three LEDs using multiple digital output pins.

## 📚 Concepts Learned
- Controlling multiple LEDs
- Sequential blinking
- Working with multiple output pins
- Timing and delays

## 🛠️ Components Used
- Arduino board
- 3 LEDs
- 3 Resistors
- Breadboard
- Jumper wires
